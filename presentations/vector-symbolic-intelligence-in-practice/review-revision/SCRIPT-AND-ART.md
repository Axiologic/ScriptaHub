## Complete spoken draft

### 1. Vector-Symbolic Intelligence in Practice

1. Vector-Symbolic Intelligence in Practice asks what a vector representation actually preserves.
2. This experimental research book audits fifteen repositories from a human-directed, AI-assisted program.
3. Its most revealing tests separate useful retrieval from the structure needed for reasoning.
4. You learn to ask which distinctions an impressive result has really tested.

### 2. Same words, different help

1. One audit compares Alice helping Bob with Bob helping Alice.
2. The tested encoder bundles word vectors without preserving their order or roles.
3. Both sentences therefore produce exactly the same vector, despite reversing who helps whom.
4. The collision comes from the encoding rule, rather than too few dimensions.
5. For topic search, grouping these sentences together can still be useful.

### 3. Give the roles a place

1. For a question about who helped, the book proposes preserving an explicit event.
2. The event records Alice as actor, helps as action, and Bob as recipient.
3. Reversing the participants now changes the event rather than disappearing inside shared words.
4. Role binding could encode those distinctions after language has been parsed.

### 4. Know where correction lives

1. The parser must still identify the roles correctly in the first place.
2. Keeping the event inspectable makes that a separate, traceable question.
3. The book extends this separation to time, evidence, and executable semantic circuits.
4. Vectors may retrieve relevant records while explicit operations preserve what the answer depends on.

### 5. Tests that change a design

1. Other experiments examine memory interference, decoding errors, and the scope of retrieved proofs.
2. Together, they motivate architectures whose representations can be inspected, revised, and tested by task.
3. The proposed circuit direction remains open research, rather than a finished replacement language model.
4. Start with Observed Role-Order Collision in Narrative Encoding for the Alice and Bob test.
5. Read onward to Make Semantic Structure Executable for the architectural response.
