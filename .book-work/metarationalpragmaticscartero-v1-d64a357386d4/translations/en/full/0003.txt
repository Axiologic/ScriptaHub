A loss function assigns a cost to a decision in a situation. If incorrectly granting access causes a loss of 100 and incorrectly denying it a loss of 1, the rational threshold is not a probability of 0.5. Assuming zero cost for correct decisions and probability p that access is legitimate, granting access has expected loss 100 × (1 − p), while denying it has loss p.
Granting access is preferable only when p exceeds 100/101, approximately 0.9901. This is a calculation about a fictional cost matrix, not an access-policy recommendation. It shows why the same uncertainty can lead to different decisions under different objectives.
Preferences do not, however, change the distribution of truth. The threshold may legitimately be changed; the probability must not be falsified to justify the desired decision. A transparent system can state: “I consider the event likely, but the cost of an error requires further checking.”
Evaluating Probabilities
Proper scoring rules are designed so that honest probabilistic prediction optimizes the expected score. Gneiting and Raftery analyze this class of methods and the distinction between calibration and the informative sharpness of predictions [
Gneiting2007
]. In an MRP experiment, these methods can prevent evaluation from being reduced to merely choosing the majority label.
For a binary outcome y equal to zero or one, a common form of Brier loss is (p − y)². If the true probability is q, expected loss can be rewritten as (p − q)² + q × (1 − q). The second term does not depend on prediction p. The first is minimized when p = q. This derivation explains why the score favors correct probabilities, not merely correct labels.
The score cannot make data representative by itself. An agent evaluated only on easy situations can score excellently and perform poorly precisely in important cases. The test distribution is part of the experiment's specification.
Abstention and Information
Abstention is an action with its own cost: delay, human intervention or a lost opportunity. It must be treated neither as absolute failure nor as a free solution. A useful technology will report the response rate, error among supplied answers and the cost of referred cases together.
More precise knowledge has value when it can change the decision in a sufficiently important way. A new observation that changes no relevant behavior may have scientific value but little operational value in the current episode. In a research program, learning's long-term value must be accounted for separately from immediate success.
For MRP, probability describes what the agent estimates, loss expresses what matters for the task, and verification establishes what support exists. These are three distinct objects. Keeping them separate enables metareasoning that saves computation without turning economy into permission to invent facts.

Representations and Equivalences
What the Agent May Forget
Every finite representation selects. It preserves some differences and ignores others. The problem is not eliminating every loss, but identifying losses incompatible with the task. A summary omitting the cover's color may be perfectly adequate for analyzing arguments. The same summary is insufficient for identifying the edition by its appearance.
We fix a family T of tests. A test may be a question with a verifiable answer or a procedure for interacting with the environment. Initially, we consider deterministic tests. Two histories are equivalent relative to T if every test in T produces the same answer for both histories.
h1 is T-equivalent to h2 exactly when Test(h1) = Test(h2) for every Test in T.
The relation is reflexive, symmetric and transitive because equality of answers has these properties. It produces a partition of histories. This partition specifies which information can be ignored without changing answers to the declared tests. It does not specify what can be ignored for every imaginable future question.
The Sufficient Representation
A representation R is sufficient for T if every test can be solved using only R(h). In a finite domain without computational restrictions, this is equivalent to requiring that R not merge histories with different answers to a relevant test.
The proof is direct. If two histories receive the same representation, any function seeing only the representation will produce the same result for them. It therefore cannot reproduce two different answers. Conversely, if all answers within each R class are identical, we can assign that answer to the class. This constructs a function on representations that reproduces the test.
The result concerns information. The constructed function may require a very large table or be difficult to compute. Information sufficiency is not the same as efficient access to it. A raw archive may contain everything needed, while a specialized procedure makes the information usable within an acceptable time.
The partition induced by T is the coarsest partition sufficient for these tests. Any other sufficient representation must preserve at least its distinctions. This formulation does not imply unique syntax: the same classes can be encoded through numbers, labels, programs or other objects.
A Provable Limit
We return to granting and revoking access. Suppose every history is fully available before compression, the last operation determines the state, and the representation preserves only the set of operations. The two orderings receive the same representation. If they occur with equal probabilities, no predictor seeing only that representation can exceed an expected accuracy of 50% on this pair.
A deterministic predictor must choose an answer and is wrong on one case. A randomized predictor saying “yes” with probability p has accuracy 0.5 × p + 0.5 × (1 − p), still 0.5. Randomization does not reconstruct the lost order.
The claim ceases to apply if the predictor sees another information source: memory of the episode, a case identifier correlated with the answer or the raw history. An experiment about information loss must therefore control every input channel, not just the vector the author calls the “representation.”
For a finite labeled dataset, the best classification based exclusively on R chooses the majority label in each R class. The minimum number of errors is the total number of examples minus the sum of the majority frequencies across classes. This bound can be calculated exactly, providing a diagnostic tool before training a more complex predictor.
Refinement as Learning
If a new function D separates the confused cases, we can define Rnew(h) = (R(h), D(h)). The new representation preserves the old information and adds the distinction. D may be a computable question: the last operation, the number of cancellations, the existence of an exception or the author of a statement.
This is what the expression “a dimension is a program” means. The dimension need not be an uninterpreted real number. It may be a discrete result or a relational structure. The agent learns an operation that changes what it can observe in its own data.
Refinement may require no new external observations, but it is not computationally free. Computing D may require rereading a long archive. If the archive was discarded, D may become impossible to apply retrospectively. Memory design determines which kinds of later learning remain possible.
What Compression Does Not Guarantee
A representation sufficient for today's questions may be insufficient for tomorrow's. We can manage this limit by preserving sources, using multiple representations and allowing requests for new observations. We cannot eliminate it with a universal assertion that “the agent understood the essence.” Operational essence must be related to a family of uses.
Information theory distinguishes measuring and encoding information from semantically interpreting messages; this boundary is explicit in Shannon's work [
Shannon1948
]. MRP adds a design question: which information must be conserved for relevant tests and decisions? A highly compressed file may remain difficult to use, while a redundant representation may enable rapid answers.
The final criterion is therefore not “how small is the memory?” but “which competence is preserved, at what construction and usage cost, for which task distribution?” This question will govern both interpreter learning and evaluation.

Learning States
A Small Protocol
Consider a fictional protocol with three states: inactive, pending and active. A request moves the system from inactive to pending. A confirmation activates only an existing request. A cancellation returns it to inactive. To avoid ambiguity, a repeated request does not deactivate access that is already active, and confirming active access leaves it active.
The agent does not see the state name. It sees operations and can ask whether access is active. Two histories, the empty history and a history containing a request, produce the same negative answer to the current question. Yet after confirmation, their answers differ. State cannot be identified by the present result alone; responses to continuations matter.

Automata and Minimal Memory
A finite automaton has finitely many states and a transition rule for every admissible input. Its state summarizes what must be retained about the past for the model's future behavior. An automaton is not a necessary explanation of the brain, but a mathematical object suited to protocols and discrete processes.
For regular languages, the Myhill–Nerode principle identifies histories that no continuation can distinguish with respect to acceptance. In active automata learning, this perspective leads to constructing states from answers to queries. Dana Angluin's L* algorithm is a fundamental reference, and generalizations to reactive systems and decision processes show its relevance beyond simple string recognition [
Angluin1987
Tappler2019
For MRP, the lesson is not that every concept must be reduced to automata. It is that some of the agent's internal entities can be constructed from tests' inability to distinguish histories. A state becomes a hypothesis about future behavior, rather than a manually assigned semantic label.
Why Closure Matters
If two histories are considered equivalent, applying the same operation must lead them to states that remain equivalent. Otherwise, the transition from their shared class is not well defined. For string continuations, this property is called right congruence.
Equivalence for all relevant continuations has this property: a continuation distinguishing the successors could be preceded by the common operation and distinguish the initial histories. But equivalence for an arbitrarily chosen finite list of tests need not have it. In our protocol, the “access now” test merges inactive and pending states, although confirmation separates them.
A test basis must therefore be evaluated for updating, not merely for the immediate answer. A representation answering correctly today but incapable of correct updating after the next event is not a sufficient state of the dynamic system.
A Learning Loop
The agent can maintain a table with representative histories as rows and test continuations as columns. Identical rows suggest the same state. When a new continuation produces different answers, the rows are separated. When an operation leads to a row type not yet represented, a new representative must be introduced.
